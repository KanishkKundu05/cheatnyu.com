❖   We usually consider multiplying two integers to be a basic operation (so takes constant
    time)
    ❖   Computers have dedicated hardware to multiply two integers up to a given size very

    ❖   Not reasonable to consider this a basic operation

❖   (Array implementation)
❖   Represented by array A[1…n] that corresponds to binary tree
❖   Associated variable A.heap-size stores the number of elements in the heap
❖   Only elements in first A.heap-size entries are in the heap (remaining elements are garbage)
❖   Corresponding tree is the one you’d get by adding the A.heap-size entries to a binary tree, level by level, from left to right
❖   Associate each node of tree with corresponding array index

     ❖   A[parent(i)] >= A[i]

                                Max-Heapify(A,i)

❖   Assumes that the left and right subtrees of node i are max-heaps
    ❖   but tree rooted at node i might not be a max-heap
        ❖   A[i] might be less than A[left(i)] and A[right(i)]
❖   Rearranges elements in tree rooted at node i to turn it into a max-heap
    ❖   How? “Bubble down” (see next slide)
                                   Max-Heapify(A,i)
❖   Max-Heapify(A,i)
    ❖   Compare A[i] to elements in left and right children of node i (if they exist)
    ❖   If no children, or A[i] greater than or equal to those elements, done
    ❖   else swap elements in A[i] and child with larger element, and recursively call Max-Heapify on
        that child

❖   Correctness of Build-Max-Heap
     ❖   Relies on fact that all descendants of node i have indices higher than i
     ❖   Loop Invariant: At start of each iteration of for-loop, nodes i+1 through n are all roots of Max-Heaps
          ❖   Base case: Property holds for i=⌊n/2⌋ because nodes ⌊n/2⌋ + 1,…, n are all leaf nodes
          ❖   Maintenance: Assuming property holds before an iteration, children of node i are both roots of Max-Heaps. So calling Max-
              Heapify(A,i) makes node i the root of a Max-Heap, values not in that Max-Heap remain unaffected.
              So before next iteration, nodes ⌊n/2⌋, …, n are all roots of Max-Heaps.
          ❖   Termination: Clear it terminates. At end, i=0, so by Loop Invariant, node 1 is root of Max-Heap
