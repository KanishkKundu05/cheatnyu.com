                                     Proof by (Weak) Induction
❖   Want to prove a proposition P(n) is true for all integers n ≥ 1
❖   Proposition P(n) is a statement about n that is either True or False, e.g.,
               n

              ∑
          ❖
                    i = n(n + 1)/2
              i=1

          ❖   n 2 ≥ 8n + 1
❖   Approach: “Weak” induction
     ❖   Base Case: Prove P(n) is true for n = 1
     ❖   Let n be an integer such that n > 1
     ❖   Induction Hypothesis:
          ❖   Assume P(n − 1) is true
     ❖   Induction Step:
          ❖   Show, using the induction hypothesis, that P(n) is true




                                                                           14
                   Principle of Weak Induction


❖   Base case shows P(n) is true for n = 1
❖   Since it’s true for n = 1, induction step tells us it’s true for n = 2
❖   Since it’s true for n = 2, induction step tells us it’s true for n = 3
❖   …

                                       19
                          Proof by Strong Induction
❖   Want to prove P(n) is true for all integers n ≥ 1
❖   Approach: Strong induction [use a stronger induction hypothesis]
    ❖   Base Case: Prove P(n) is true for n = 1
    ❖   Let n be an integer such that n > 1
    ❖   Induction Hypothesis:
        ❖   Assume P(k) is true for k=1, 2, 3, 4, …, n − 1
    ❖   Induction Step:
        ❖   Show, using the induction hypothesis, that P(n) is true
