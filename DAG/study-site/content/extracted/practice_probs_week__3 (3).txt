The Master Theorem (as stated in lecture): for a recurrence of the form
                  T (n) = aT (n/b) + Θ(nd ) if n ≥ n0 ,      T (n) = Θ(1) if n < n0 ,
where a, b, d, n0 are constants with a > 0, b > 1, d ≥ 0, n0 > 0:

                                        ⎨Θ(n log n) if d = logb a
                                        ⎧
                                        ⎪     d

                                T (n) = Θ(nlogb a )     if d < logb a
                                                        if d > logb a
                                        ⎪
                                        ⎩     d
                                          Θ(n )

Problem 1 : Practice with the Master Theorem
For each recurrence below, identify the constants a, b, and d. Then compute logb a, compare it with
d, determine which case of the Master Theorem applies, and state the corresponding asymptotic
bound.
 (a) T (n) = 4T (n/2) + Θ(n2 )
 (b) T (n) = 3T (n/3) + Θ(1)
 (c) T (n) = 7T (n/2) + Θ(n2 )
 (d) T (n) = 2T (n/4) + Θ(n)
 (e) T (n) = 2T (n/2) + Θ(n log n)

 Solution. (a) a = 4, b = 2, d = 2.

     • logb a = log2 4 = 2.

     • Since d = 2 = log2 4, this is the case where d = logb a.

     • T (n) = Θ(nd log n) = Θ(n2 log n).

     (b) a = 3, b = 3, d = 0 (since Θ(1) = Θ(n0 )).

     • logb a = log3 3 = 1.

     • Since d = 0 < 1, this is the case where d < logb a.

     • T (n) = Θ(nlogb a ) = Θ(n1 ) = Θ(n).

     (c) a = 7, b = 2, d = 2.

     • logb a = log2 7 ≈ 2.807.

Problem 3 : Debugging divide and conquer
Recall in lecture we discussed an initial approach to the Maximum Sum Subarray problem where the
divide and conquer approach was flawed. Before the fix we had: recursively find the max subarray
sum of the left half, recursively find the max subarray sum of the right half, and return the larger
of the two (never considering subarrays that span the middle).
    Let A = [−2, 1, −3, 4, −1, 2, 1, −5], split into left half [−2, 1, −3, 4] and right half
[−1, 2, 1, −5].
 (a) Find the maximum subarray sum within the left half alone, and within the right half alone.
     What does this initial approach return for A?
 (b) Using the corrected algorithm from lecture (which additionally computes maxPrefix and max-
     Suffix), state which suffix of the left half and what prefix of the right half combine to give the
     actual maximum subarray sum of A.
 (c) Now identify the actual maximum subarray sum of A, and state the subarray that gives this
     result.

 Solution. (a) From all the subarrays, we see that the maximum sum (for the left side) is 4,
 which is given by [4]. For the right side, the maximum sum is 3, which is given by [2, 1]. The
 flawed approach returns max(4, 3) = 4.
     (b) The crossing subarray [4, −1, 2, 1] splits exactly at the middle boundary into a suffix of
 the left half, [4] (sum 4), and a prefix of the right half, [−1, 2, 1] (sum 2).
     (c) The actual maximum subarray sum of A is 6, which is given by [4, −1, 2, 1]. This subarray
 starts at the last position of the left half and continues into the right half, so it belongs to neither
 of two exclusively.


Problem 4 : Tracing Karatsuba’s algorithm
Use Karatsuba’s algorithm to multiply the 4-bit numbers x = 11012 (= 13) and y = 01102 (= 6).
 (a) Split x and y into their high and low halves: xL , xR , yL , yR (as bit-strings and as decimal
     values).
 (b) Compute the following: P1 = xL yL , P2 = xR yR , and P3 = (xL + xR )(yL + yR ).
 (c) Compute xL yR + xR yL using P3 − P1 − P2 , and check it against xL yR + xR yL .
 (d) Combine everything with the equation 2n P1 + 2n/2 (P3 − P1 − P2 ) + P2 (here n = 4) to get the
     final product, and verify it equals x · y.

 Solution. (a) x = 11012 splits into xL = 112 = 3 and xR = 012 = 1. y = 01102 splits into
 yL = 012 = 1 and yR = 102 = 2.
    (b) P1 = xL yL = 3 · 1 = 3. P2 = xR yR = 1 · 2 = 2. xL + xR = 4, yL + yR = 3, so
 P3 = 4 · 3 = 12.

 (a) For each of nodes 1 through 5, state the value stored there, and the values stored at its left

 (b) Double check that A satisfies the max-heap property (every node’s value is ≥ the values of
     both its children) for every node.

 (c) What is the height of this heap (the number of edges on the longest root to leaf path)?


 Solution. (a) Node 1 (value 78): children at indices 2, 3, values 61, 70. Node 2 (value 61):
 children at indices 4, 5, values 57, 39. Node 3 (value 70): children at indices 6, 7, values 32, 66.
 Node 4 (value 57): children at indices 8, 9, values 26, 23. Node 5 (value 39): has only a left

     (b) Node 1 (78) ≥ its children (61, 70). Node 2 (61) ≥ its children (57, 39). Node 3 (70)
 ≥ its children (32, 66). Node 4 (57) ≥ its children (26, 23). Node 5 (39) ≥ its one child (29).
 Every check holds, so A is a valid max heap.
     (c) Node 1 is at depth 0, nodes 2, 3 at depth 1, nodes 4, 5, 6, 7 at depth 2, and nodes 8, 9, 10
