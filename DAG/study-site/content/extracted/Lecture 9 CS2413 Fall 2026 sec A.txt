                      Linearity of Expectation


❖   We will use following important property called “Linearity of Expectation”
❖   For any two random variables X and Y, and constants a and b
      ❖   E[aX + bY] = aE[X] + bE[Y]
❖   True even if X and Y are not independent!

                           Avoiding bad splits
❖   Idea:
    ❖   Choose a random element to be the pivot!
❖   This results in a Randomized Algorithm
    ❖   Algorithm uses randomness in its execution (in practice, random number
        generator)
    ❖   Execution of the algorithm on an input x is not always the same, depends
        on the random choices made by the algorithm
              Runtime of randomized algorithms?
❖   Instead of asking:
    ❖   What is the runtime of Algorithm Q on input x
❖   Ask:
    ❖   What is the expected runtime of Algorithm Q on input x

    We talk about the “worst-case running time” of a deterministic (not randomized) algorithm A

                        Randomized Quicksort

❖   (Deterministic) Quicksort always performs n(n-1)/2 comparisons if input
    array was already sorted.
    ❖   Quicksort is doomed to perform badly if input array is sorted
❖   Randomized-Quicksort not doomed in this way
    ❖   No matter what input array is given, expected number of comparisons
        performed by Randomized Quicksort will be much less than n(n − 1)/2
        (as long as n not very small).
