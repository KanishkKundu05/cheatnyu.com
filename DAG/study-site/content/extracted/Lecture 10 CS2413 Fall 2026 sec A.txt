Proof of Ω(n log n) lower bound on comparison sorting
 ❖   Let Alg be a comparison sort algorithm
 ❖   Consider using Alg to sort an array A of length n
 ❖   Consider associated decision tree showing comparisons performed by the algorithm
       ❖   Binary tree
       ❖   Each node has a comparison between two elements of the input array
       ❖   Each leaf of the decision tree has a permutation of elements of A
 ❖   Worst-case number of comparisons performed by Alg = height of tree
 ❖   There must be one leaf for every possible permutation of elements of A
       ❖   n! possible permutations
       ❖   Tree has at least n! leaves
       ❖   Height of tree is at least log2(n!)
 ❖   Worst-case number of comparisons performed by Alg is at least log2(n!) = Ω(n log n)
 ❖   Since Alg is an arbitrary comparison sort algorithm, this proves the theorem.

❖   When computer were still very expensive, people used mechanical sorting machines to help
    do sorting, using principle of radix sort
    ❖   Each number to be sorted was on a separate “punch card”
    ❖   Knob on the machine determined the column on which to perform sort
❖   Today, sometimes used when sorting with multiple keys
    ❖   e.g., want to sort by date, and date is represented by year, month, day
❖   When sorting n numbers, each of b-bits, can choose r ≤ b and use radix sort with k = 2r − 1 by
    breaking b bits into r-bit “digits”
    ❖   Runtime is O((b / r)(n + 2r))
